# Skelefetch

Minimal, fast and clean system fetch for the terminal.

![preview](https://i.imgur.com/WNKbJE2.png)

## ✨ Overview

Skelefetch is a lightweight system fetch tool built with Node.js.  
It displays essential system information in a clean and readable format directly in your terminal.

Fully open-source and designed to be easily customizable.

> Inspired by neofetch by Dylan Araps  
> https://github.com/dylanaraps/neofetch

## ⚙️ Features

- Clean and minimal layout
- Fast execution
- Built with Node.js
- Fully customizable output
- Open-source
- System info overview (OS, kernel, CPU, memory, uptime, etc.)
- Custom ASCII logo support

## 🚀 Usage

Run it with Node.js:

```bash
node .\skelefetch.js
```
